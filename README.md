# ecoExpert: versões

Instaladores e atualizações do **ecoExpert**, IDE para Firebird (2.5 a 6) e PostgreSQL (13 a 19) no Windows.

- Baixe o instalador em [Releases](../../releases): `ecoExpert_<versão>_x64-setup.exe` (instala só para o seu usuário) ou o
  `.msi`.
- O próprio ecoExpert procura as atualizações aqui (`latest.json` no canal estável, `latest-beta.json` no beta) e só instala
  as que vêm com a assinatura da chave do projeto.
- O instalador ainda não tem assinatura de código: o Windows avisa na primeira execução ("Mais informações" e "Executar
  assim mesmo").

Este repositório guarda só os binários publicados; o código-fonte é privado.
